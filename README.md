# Library Management System

A simple console-based Library Management System built using **Java** and **MySQL**.

## Features

- Add new books
- View all books
- Search books
- Issue books
- Return books
- Basic database connectivity using JDBC

## Technologies Used

- Java
- MySQL
- JDBC

## How to Run

1. Clone the repository
2. Open the project in your IDE (VS Code / IntelliJ / Eclipse)
3. Make sure MySQL is installed and running
4. Update database credentials in `DBConnection.java`
5. Add MySQL Connector JAR to your project
6. Run `LibraryApp.java`
